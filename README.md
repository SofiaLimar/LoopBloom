# LoopBloom

**Ver o site:** https://sofialimar.github.io/LoopBloom/

Landing page de um ateliê fictício de bolsas de crochê feitas à mão.

> **Projeto conceitual.** Desenvolvido para fins acadêmicos e de portfólio de design. O site é fictício: as peças não estão à venda e as encomendas não são processadas.

## Sobre

Página única (HTML, CSS e JavaScript puros, sem build) com hero editorial, galeria de bolsas, simulador de encomenda, seção "Quem faz" e perguntas frequentes.

- **Tipografia:** Cormorant Garamond (títulos), Outfit (texto), Tenor Sans (logo e faixa) e Caveat (assinatura), via Google Fonts.
- **Paleta:** creme de linho, terracota (`#c4573f`) e marrom espresso.

## Como ver

Abra `index.html` no navegador, ou publique a pasta no GitHub Pages (Settings > Pages > Deploy from a branch > `main` / root).

## Estrutura

- `index.html`: a página inteira.
- `img/`: imagens otimizadas usadas no site (inclui `og.jpg`, a prévia do link).
- `originais/`: fotos originais em alta resolução (ignoradas pelo Git, ver `.gitignore`).
